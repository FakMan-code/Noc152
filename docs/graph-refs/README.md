# Referencias de grafos 3D

Ejemplos bajados de [vasturiano/3d-force-graph](https://github.com/vasturiano/3d-force-graph) para guiar la UI de Noc152.

| Archivo | Idea a rescatar |
|---|---|
| `3d-force-graph-html-nodes.html` | Labels HTML (CSS2D) con pill legible sobre el nodo |
| `3d-force-graph-text-nodes.html` | SpriteText siempre de cara a cámara |
| `3d-force-graph-highlight.html` | Vecindario resaltado al hover |
| `3d-force-graph-custom-geometry.html` | Forma distinta por tipo de nodo |

En Noc152 aplicamos: etiqueta con **tipo + nombre**, forma por `kind`, halo en principal, bordes con color propio.
